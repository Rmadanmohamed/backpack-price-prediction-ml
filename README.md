# Backpack Price Prediction ML

## Overview
A regression notebook for backpack price prediction using tabular product data and classical machine learning models.

## Problem Statement
Product pricing workflows need interpretable regression baselines that handle categorical product attributes and validation metrics.

## Features
- EDA and visualization
- Categorical preprocessing
- Regression model comparison
- Submission file generation

## Tech Stack
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Dataset
- train.csv
- test.csv
- training_extra.csv
- sample_submission.csv

## Models / Algorithms
- Random Forest
- KNN
- SVM
- Decision Tree
- Logistic Regression references

## Results
The notebook includes MSE and RMSE evaluation code. No single final metric was extracted as a verified result.

## Project Structure
- notebooks/
  - backpack-price-prediction.ipynb

## How to Run
- `pip install -r requirements.txt`
- `jupyter notebook notebooks/backpack-price-prediction.ipynb`
